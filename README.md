# Ayu Study Tracker

An original, simple Class 9 study-tracking web app made for Technical Ayu.

Features:
- Student profile
- Exam date
- Subject/topic tracker
- Completed/not-completed status
- Daily target
- Progress percentage
- Light/dark theme
- Saves data in the browser with localStorage

This project is an independent implementation and does not copy the source code, branding, or assets of another Study Tracker.
